# Achievement Plaques 0.1.8

## Added

- Adds direct access to Steam's official Web API key-registration page from mod settings and plaque configuration.
- Adds clearer local-only API-key setup guidance.
- Adds full player documentation covering placement, completion plaques, individual achievements, data refresh and troubleshooting.

## Improved

- Uses a visible gunmetal frame against dark BOXROOM walls.
- Uses neutral graphite for the base completion tier while preserving distinct bronze, silver and gold awards.
- Adds restrained brushed-metal grain and satin highlights so tier colours remain readable without a strong direct reflection.
- Keeps the personal Steam Web API key as an optional fallback after the local cache and keyless Community feed.
